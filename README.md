# 🐾 Pet SaaS — Assistente Virtual para Pet Shops
Projeto desenvolvido para a A3 da graduação em Análise e Desenvolvimento de Sistemas.
O Pet SaaS é uma solução de atendimento automatizado para pet shops, utilizando inteligência artificial para responder dúvidas dos clientes, consultar disponibilidade de horários e realizar agendamentos pelo WhatsApp.
### 🎯 Objetivo
Facilitar o atendimento dos pet shops e melhorar a organização dos agendamentos, considerando a disponibilidade dos funcionários e os serviços oferecidos.
